DIAGRAM: Perimeter Control Layers
PURPOSE: Shows the layered defense-in-depth model for inbound perimeter controls, from Edge (global) through VPC Inspection, Subnet Boundary, down to Resource layer. Traffic flows inward through these layers sequentially, and each layer can independently deny traffic.
LAYOUT: top-to-bottom (sequential layers)
WIDTH: 700px maximum readable width

GROUPS:
- Edge Layer (Global): border style dashed, color orange (#ff9900); contains CloudFront+WAF, Shield
- Inspection Layer (VPC): border style dashed, color blue (#2563eb); contains Network Firewall, GWLB
- Subnet Boundary Layer: border style dashed, color purple (#7c3aed); contains NACLs
- Resource Layer: border style dashed, color green (#059669); contains Security Groups, ENI

NODES:
Edge:
- CloudFront + WAF: AWS icon "Amazon CloudFront", label "CloudFront + AWS WAF"
- Shield: AWS icon "AWS Shield", label "AWS Shield\n(Standard + Advanced)"

Inspection:
- Network Firewall: AWS icon "AWS Network Firewall", label "AWS Network Firewall"
- GWLB: AWS icon "Elastic Load Balancing (GWLB resource icon)", label "Gateway Load Balancer\n+ Third-party firewalls"

Subnet Boundary:
- NACL: generic icon, label "Network ACLs"

Resource:
- Security Groups: generic icon (shield), label "Security Groups"
- ENI: generic icon, label "Elastic Network Interface"

CONNECTIONS:
- Edge Layer → Inspection Layer: style solid, no label
- Inspection Layer → Subnet Boundary Layer: style solid, no label
- Subnet Boundary Layer → Resource Layer: style solid, no label

NOTES:
- BACKGROUND: Transparent (no white background). All text and lines that appear directly on the transparent background must use #7E7E7E instead of black (#000000). Text and lines inside colored nodes/shapes can remain as-is (white on colored fill is fine).
- Four layers stacked top-to-bottom showing traffic flowing inward
- Arrows between layers show sequential evaluation
- Orange for edge (global AWS), blue for inspection (route-table-steered within VPC), purple for subnet boundary (NACLs), green for resource (Security Groups → ENI)
- Each layer can independently block traffic — this is defense in depth
- The visual should clearly show the narrowing funnel from internet to resource
- Security Groups wrap around the ENI inside the Resource Layer to show they enforce at the network interface
- Global Accelerator is intentionally excluded — it is a routing/performance tool, not a perimeter control
